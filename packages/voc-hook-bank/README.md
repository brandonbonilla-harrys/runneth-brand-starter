# VoC Hook Bank

Mines the brand's own customer voice (reviews and ad comments) into a bank of ad-ready hooks and
angles, each tied to a verbatim customer quote with attribution (reviewer name + rating, or the
comment source). It's the input bank the ideation and briefing work pulls from.

Reads the brand-product profile and the brand's connected reviews/comment sources.

- `sop.md` — sourcing, extraction into the seven VoC buckets, hook drafting, and the bank format.
- Requires `brand-product-foundation`; a connected reviews platform and/or Meta comments.

Nothing runs on install. The bank is built only after an explicit yes.
