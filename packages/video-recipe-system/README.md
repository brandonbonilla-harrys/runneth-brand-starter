# Video Recipe System

Turns the brand's winning video ads into repeatable recipes: the hook, the script structure, and
a shot list a producer can brief a new cut from. Recipes are derived from the transcripts of the
brand's own top videos plus inspo teardowns, so they reflect what actually works for this brand.

Reads the brand-product profile. Pairs with `producer-cockpit`.

- `sop.md` — how recipes are built from transcripts, stored, and reused in briefs.
- Requires `brand-product-foundation`.

Nothing runs on install. Recipe building happens only when asked.
