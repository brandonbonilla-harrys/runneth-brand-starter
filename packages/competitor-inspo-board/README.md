# Competitor & Inspo Board

A browsable board of competitor and inspiration creatives the team can scan, filter, and pull
from when briefing. Built from the competitor roster plus the workspace's followed inspo brands
and saved inspo boards.

Rebuilt fresh in the brand's instance at setup. Honors a video-only preference if the brand wants
only video inspo.

- `build-spec.md` — blueprint: data sources, filters, layout, refresh.
- Requires `brand-product-foundation`; works best alongside `competitor-roster`.

Nothing runs on install. Built only after an explicit yes; private by default.
