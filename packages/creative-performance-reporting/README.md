# Creative Performance Reporting

Two recurring reports over the installing brand's own Meta data:

- **Daily performance report** — spend, day-over-day and trailing movers, plus delivery/spend
  anomaly and high-spend fatigue guards, in one send.
- **Monthly creative strategy digest** — the "here's what to do this month" brief: what's
  scaling, what's fatiguing, where the whitespace is, and a short concept slate.

Both are Meta-attributed and workspace-agnostic. They run against whatever workspace they are
set up in. Nothing here assumes a specific brand, product set, or attribution vendor.

## Files

- `daily-performance-report.md` — the daily report contract.
- `monthly-strategy-digest.md` — the monthly digest contract.

## Setup

Setup does not run on install. When you ask to turn these on, the activation flow will confirm
the workspace, the delivery destination (a web conversation or a Slack channel), and the send
times, then create the routines. See the activation instruction for details.
